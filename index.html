Our Manifesto

We didn't find each other.
The code brought us together.

Forged in the lecture halls of The ICT University, ten minds converged over late-night debugging sessions, shared terminals, and relentless ambition. What began as classmates became a brotherhood bound by one common drive — to become world-class engineers.

The Palace is not a team. It is a standard. We build, ship, and iterate with precision. Every line of code is a declaration: we are here, we are capable, and we are just getting started.

Featured Projects

What we ship.

Case studies from our most impactful work — built with intent, shipped with precision.

01

NexusFlow

Enterprise Workflow Automation Platform

A full-scale SaaS platform enabling businesses to visually design, automate, and monitor multi-step operational workflows. Features real-time collaboration, conditional logic branching, webhook integrations, and a role-based access control system. Handles over 500K events per day in production.

  • Node.js
  • React
  • PostgreSQL
  • Redis
  • Docker
  • AWS
02

QueryForge

Intelligent Database Wrapper & ORM Layer

An open-source, type-safe database abstraction layer for JavaScript and TypeScript. Supports PostgreSQL, MySQL, and SQLite with a fluent query builder, automatic migration generation, and query performance analytics. Adopted by 1,200+ developers worldwide with 4.8k GitHub stars.

  • TypeScript
  • PostgreSQL
  • MySQL
  • SQLite
  • Jest
03

VaultShield

Zero-Trust Security & Secrets Management System

A self-hosted secrets manager and access control system designed for startups and dev teams. Features end-to-end encryption, dynamic credentials, audit trail logging, and a Slack/Teams integration for access request approvals. Built as a lean alternative to enterprise vault solutions.

  • Go
  • AES-256
  • Linux
  • MongoDB
  • Terraform
04

PulseBoard

Real-Time Analytics Dashboard & Data Visualisation Engine

A live analytics web application that ingests event streams and renders customizable dashboards for product and growth teams. Features drag-and-drop widget configuration, multi-source data connectors, threshold-based alerting, and PDF report exports.

  • React
  • WebSockets
  • Apache Kafka
  • ClickHouse
  • D3.js
